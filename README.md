# LAMP-SYS
## How to edit
To edit the projects page, simply add the information you wish to add into _pages/projects.md.  
Similarly for downloads, edit the download page at _pages/downloads.md   
To add new people, go to _data/people.yml and add their name, upload an image to images/people and then put the name of the image, then add their google scholar link and personal page link as shown in people.yml. There's sections for faculty, phd student, masters students, undergrad, and past of all of those. 
To add new publications, first go to the publications page, and then press manage citations. 
After that, enter the citation data into the form and press submit, it will populate the database and show up below the form as well as on the publication page.
